# مولّد كروت الدوام

صفحة واحدة تقرأ شيت «كروت دوام جميع الشركات» مباشرة وتطلّع كرت دوام شهري لكل موظف (من 21 الشهر السابق إلى 20 الشهر المختار)، لكل التبويبات: شركة زحل، مصنع الباحة، مصنع جدة، الورش.

- اختر الجهة ← الشهر ← الموظف، ثم «إنشاء الكرت» أو «كل الموظفين».
- «طباعة / حفظ PDF» تطبع كل كرت في صفحة A4.
- الشعارات في مجلد `logos`.
